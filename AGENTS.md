# Agent instructions

Read [README.md](README.md), [CONTRIBUTING.md](CONTRIBUTING.md) and every file in
[docs/](docs/) before doing anything.

## Hard rules

- This repo is public. Work only inside it: never read, copy or reference files from any
  other repository or folder on the machine, even an Apolarion one.
- Never invent lore, names, factions, places or abilities. The brief is the whole context;
  if it is unclear, ask the human.
- Every image comes from an image-generation tool and ships with its record. Never draw
  images with code (SVG, Pillow, canvas, ImageMagick) as a substitute.
- No absolute paths, usernames, tokens or personal data in any committed file.
- Run `python tools/check.py` before every commit; it must pass.
- Never edit `docs/` or `tools/` in a submission PR.
