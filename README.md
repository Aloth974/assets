# Apolarion shared assets

Public workshop for Apolarion art: friends with spare AI
subscription usage generate candidate assets from open briefs, and accepted ones go into
the game.

- [docs/style.md](docs/style.md): the art direction every asset is judged against.
- [docs/specs.md](docs/specs.md): sizes, formats, naming and prompt starters.
- [CONTRIBUTING.md](CONTRIBUTING.md): how to pick a brief, submit and get reviewed.
- [briefs/](briefs/): open requests. [archive/](archive/): accepted assets.
